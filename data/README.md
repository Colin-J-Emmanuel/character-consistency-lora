# Character dataset

Put **8–15 images of ONE character** in `my_character/`.

Guidelines that make or break the result:
- Same identity in every image; varied pose, angle, expression, and lighting.
- Crop reasonably tight to the subject; avoid other prominent people.
- Roughly square crops work best for 1024x1024 SDXL training.
- Consistent enough to learn an identity, varied enough to avoid memorizing one pose.

You can use a real person you have rights to, an existing licensed character asset,
or generate a synthetic "character sheet" first and train on that. Document whatever
you choose in the top-level README so provenance is clear.
